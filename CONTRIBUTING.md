# Contributing Guidelines

Thank you for considering contributing to this project!

## Getting Started
1. Fork the repository and clone it locally.
2. Follow the setup instructions in the `README.md` to configure your environment and install dependencies.

## How to Contribute
- **Reporting Bugs:** Check open issues first. If your issue isn't listed, open a new issue with steps to reproduce and system details.
- **Suggesting Features:** Open an issue outlining the proposed change and its use case before opening a Pull Request.
- **Submitting Pull Requests:**
  1. Create a descriptive branch (e.g., `git checkout -b feature/my-feature`).
  2. Write clean code and follow existing code style.
  3. Ensure all tests pass locally.
  4. Push your branch and open a PR with a clear summary of your changes.

## Code of Conduct
Please ensure all interactions in this project remain respectful and constructive.
